# Assets Directory

Esta carpeta contiene los recursos del sitio web (imágenes, logos, etc.)

## Logo

Por favor, coloca el logo de UFAACYM Chile en este directorio con el nombre:
- `logo-ufa.png`

El logo debe estar en formato PNG con fondo transparente para mejor visualización.

### Especificaciones recomendadas:
- **Formato**: PNG con transparencia
- **Dimensiones recomendadas**: 500x500px (mínimo 200x200px)
- **Tamaño de archivo**: < 500KB
- **Nombre del archivo**: `logo-ufa.png`

## Otras imágenes

Si deseas agregar más imágenes al sitio:
- Usa formatos web optimizados (WebP, PNG, JPG)
- Comprime las imágenes antes de subirlas
- Usa nombres descriptivos (ej: `retiro-2026-banner.jpg`)
- Mantén los archivos organizados

## Estructura sugerida

```
assets/
├── logo-ufa.png           # Logo principal
├── favicon.ico            # Icono del sitio (opcional)
├── images/                # Otras imágenes (opcional)
│   ├── hero-bg.jpg
│   └── gallery/
└── README.md              # Este archivo
```
