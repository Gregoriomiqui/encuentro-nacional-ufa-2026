# 📁 Estructura del Proyecto

```

│
├── 📄 index.html                          # Página principal del sitio

│   ├── Variables CSS personalizables
│   ├── Diseño responsive
│   ├── Animaciones y transiciones
│   └── Estilos para impresión
│
├── ⚡ script.js                           # JavaScript (8.2 KB)
│   ├── Navegación suave
│   ├── Animaciones de scroll
│   ├── Botón "volver arriba"
│   ├── Validación de formularios
│   └── Funciones de accesibilidad

│   ├── 🖼️ logo-ufa.svg                   # Logo temporal (reemplazar con oficial)

│

├── 🤖 robots.txt                          # Instrucciones para bots de búsqueda
│
├── 📚 Documentación:
│   ├── 📖 README.md                       # Documentación principal
│   ├── 🚀 QUICKSTART.md                   # Guía de inicio rápido
│   ├── 📤 DEPLOYMENT.md                   # Guía de despliegue en GitHub Pages
│   ├── 🤝 CONTRIBUTING.md                 # Guía para contribuidores
│   ├── 🖼️ LOGO_INSTRUCTIONS.md           # Instrucciones para actualizar logo
│   └── 📄 LICENSE.md                      # Términos de licencia
│
└── ⚙️ Configuración:
    └── .gitignore                         # Archivos a ignorar en Git

```
