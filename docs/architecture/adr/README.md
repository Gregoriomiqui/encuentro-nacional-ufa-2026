# Architecture Decision Records

Los ADR registran decisiones arquitectónicas transversales, costosas de revertir o con alternativas relevantes. No sustituyen una especificación funcional: una spec define comportamiento; un ADR explica una decisión técnica.

Crear el siguiente archivo numerado desde [ADR_TEMPLATE.md](ADR_TEMPLATE.md). Un ADR aceptado es inmutable; si cambia la decisión, crear otro que lo reemplace.
