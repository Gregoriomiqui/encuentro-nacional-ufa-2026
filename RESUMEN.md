## 🚀 Próximos 3 Pasos

### 1️⃣ Ver el Sitio Localmente (2 minutos)

```bash
cd /Users/josemiquilena/Programacion/personal/projectUFA
python3 -m http.server 8000
```
Luego abre: http://localhost:8000

### 2️⃣ Actualizar el Logo (5 minutos)

Lee: `LOGO_INSTRUCTIONS.md`

Resumen rápido:
1. Guarda tu logo como `assets/logo-ufa.png`
2. El sitio ya está configurado para usarlo

### 3️⃣ Publicar en GitHub Pages (10 minutos)

```bash
# Inicializar Git
git init
git add .
git commit -m "Sitio web Retiro Nacional UFA"

# Crear repo en github.com, luego:
git remote add origin https://github.com/TU-USUARIO/retiro-ufa.git
git branch -M main
git push -u origin main

# En GitHub: Settings > Pages > Source: main > Save
```

Tu sitio estará en: `https://TU-USUARIO.github.io/retiro-ufa/`
